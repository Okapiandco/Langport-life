# Managing langport.life — a guide for the Town Council office

Everything on the website is managed through the admin area, called the Studio.
This same guide is built into the Studio under the **How To** tab, so it is
always to hand while you work.

## Signing in

1. Go to **langport.life/studio**
2. Sign in with the email address Jim has set up for you (you'll receive an
   invitation email the first time — follow its link to choose how you sign in)
3. You'll see tabs across the top: **Structure** (all the content),
   **Approvals**, **Bulk Upload** and **How To**

Changes you publish appear on the live website automatically, usually within a
few minutes.

## Uploading meeting documents — the quick way

Use the **Bulk Upload** tab whenever you have a meeting's papers to publish:
agenda, minutes and all supporting documents in one go.

1. Choose the **committee** from the dropdown
2. Set the **meeting date**
3. Drag all the files into the dashed box (or click it and select several at
   once). PDF, Word and Excel files all work
4. Check the list — each file gets a title from its filename and a guessed
   type (Agenda, Minutes, Financial Report…). Click in any box to correct a
   title or type before uploading
5. Press **Upload**. Each row shows "Published" when done

The documents appear on the website under that committee, grouped by month.

**Confidential papers:** switch Visibility to "Clerk only" before uploading —
those documents will never appear on the public website.

## Adding or editing a single document

For one-off documents (a policy, a notice): **Structure → Council → Documents →
All Documents**, then the compose (pencil) icon. Fill in the title, click
Generate next to the slug field, choose the type and date, upload the file,
tick the committee under Tags, then press **Publish**.

To replace a file (for example draft minutes with the approved version), open
the existing document, upload the new file over the old one, and publish
again — the website link stays the same.

## Changing the order documents appear in

**Structure → Council → Documents → By Committee**, pick a committee, and drag
documents up and down with the handle on the left. The website shows them in
exactly this order within each month. The menu at the top right of the list
also has **Reset order** if things get muddled.

## Approving events and listings from the public

Residents and businesses can submit events, venues, business listings and
community groups through the website. **Nothing goes live until you approve
it.**

1. Open the **Approvals** tab — new submissions appear there with the
   submitter's name (you also get an email when something arrives)
2. Click a submission to read it, then **Approve** or **Reject**
3. Submitters get an edit link by email. If they later change a published
   item, it returns to Approvals for you to re-approve

## News articles

**Structure → Articles & News → All Articles**. Give the article a title,
category, a short excerpt (shown in previews and search results), an image and
the story. Tick **Published**, then press Publish. Newest articles appear
first on the Town News page.

## Events, venues, groups and listings

You can add these directly too: **Structure → Events / Venues / Business
Listings / Groups**. For events, set the date and time carefully — recurring
events (weekly classes, the Friday market) have a repeat rule so one entry
covers every occurrence. Past one-off events are tidied away automatically 30
days after they finish.

## Councillors and staff

**Structure → Council → Members** for councillors, **Council → Staff** for
staff and volunteers. When someone stands down, set their end date rather than
deleting them. Staff order on the website follows the Display Order number —
lower numbers first.

## General pages and site settings

- Standalone pages (About, policies): **Structure → Pages**
- Homepage cards, welcome text, contact details, footer, "Did you know" fact:
  **Structure → Site Settings**
- The site menus: **Structure → Navigation** (take care — a wrong link here
  affects every page)

## Good habits

- Give documents clear titles — they become the link text people see and what
  search engines index
- **Publish is what makes things live.** A saved draft (grey dot) is not on
  the website yet
- Never delete a published document to "hide" it — set Visibility to Clerk
  only instead, so the record is kept
- Made a mistake? Every document keeps its history (the Review changes clock
  icon) and any version can be restored
